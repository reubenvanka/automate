# Auto Mate Security and Privacy

- Never commit Wi-Fi credentials, Home Assistant tokens, API keys, private keys, customer data, or private commercial information.
- Keep secrets in an external secret store or local ignored file.
- Review both the working tree and Git history before publishing.
- Document non-secret configuration defaults separately from credentials.
- Treat AI-generated firmware and hardware decisions as untrusted until reviewed and tested.
- Local web authorization, network exposure, logging, and personal-data handling require explicit review before release.
